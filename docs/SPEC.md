# 책 읽는 달팽이 — 기능 명세 v1

## 1. 기록 (핵심)

- 책 1 : 기록 N. 시간순 누적. **이전 기록을 덮어쓰지 않는다.**
- 기록 타입 분리
  - `quote` 필사한 책 문장
  - `note` 내 생각·감상
- 작성 중 자동 임시저장·복구
- 전문 검색 (SQLite FTS5, **trigram 토크나이저**)
  - `unicode61`은 한글을 어절 단위로만 자른다. '독서는'이 '독서'로 안 잡힌다. 쓰지 않는다.
  - trigram은 세 글자 미만 질의를 원리상 매칭하지 못한다. 2자 이하는 LIKE로 우회한다.
  - **검색은 반드시 `storage/search.py`를 거친다.** UI가 MATCH를 직접 부르면 2자 검색이 죽는다.
- 내보내기 — Markdown / CSV. 데이터 락인 방지용이며 선택 기능이 아니다.

## 2. 책 관리

- 상태: `reading` / `completed` / `wishlist` / `paused`
- 등록: ISBN·제목·저자 검색 + 수동 입력 폴백
- 서지 API: **국립중앙도서관 ISBN 서지정보** (`nl.go.kr/seoji/SearchApi.do`, cert_key)
  - 알라딘 OpenAPI는 2026-10-30 종료. 사용하지 않는다.
  - 카카오 책 검색은 DB 영구 저장이 운영정책상 제한되므로 메인으로 쓰지 않는다.
  - **어댑터 인터페이스 뒤에 숨긴다.** 올해만 두 곳이 문을 닫았다.
- 표지는 내려받아 로컬 저장. 외부 URL을 DB에 박아두지 않는다.

## 3. 달팽이 발화

| 갈래 | 기본 가중치 |
|---|---:|
| 내 기록·감상 | 35 |
| 필사한 책 문장 | 30 |
| 위시리스트 책 제목 | 15 |
| 독서 명언 | 10 |
| 정체된 책 리마인드 | 10 |

- 기록 수에 따라 가중치 자동 조정 (콜드 스타트 대응)
- 명언 시드 24건 동봉 (`storage/seeds/quotes_ko.json`). 출처 없는 명언은 넣지 않는다.
  - 시드가 비면 기록 0건일 때 달팽이가 아무 말도 못 한다. DB 열 때 `seed_quotes()`를 부른다.
  - 추가는 새 id로 append. 사용자가 지운 명언은 `quote_seed_log` 때문에 되살아나지 않는다.
- 최근 12회 내 등장한 항목은 재추첨 제외
- 말풍선 클릭 → 해당 기록 원본으로 이동
- **의미 검색 연동**: 기록 저장 후 90~300초 사이에, 임베딩으로 찾은 가장 비슷한
  과거 기록을 뱉는다. 유사도 0.72 미만이면 억지 연결이므로 뱉지 않는다.
- 죄책감을 자극하지 않는다. 기록이 없으면 말수가 줄어들 뿐이다.

## 4. 이동

- 8방향(좌우·상하·대각선) 자유 이동
- **정면·후면 프레임 없음.** 좌향 스프라이트 + 좌우 반전만 사용
- 수직 속도는 수평의 약 절반. 그래야 나는 게 아니라 기어오르는 것으로 읽힌다.
- 화면 끝 충돌, 드래그 후 낙하

## 5. 완독 → 꿀꺽 → 책장

완독 표시 → `eat` → 껍데기로 들어감 → `shelve` → 책장에 꽂힘.
이 앱의 유일한 보상 순간이므로 연출을 끊지 않는다.

- 책등은 템플릿 5~6종 × 표지 추출 색 tint
- 기울어진 책 1~2권, 눕힌 책 1권을 섞어 정돈감을 깬다
- 완독 권수에 따라 선반이 아래로 늘어남
- 책 클릭 → 그 책의 기록 타임라인

## 6. 주간 요약

기록장 안의 탭. 이번 주 기록 수, 완독 권수, 이어 읽는 중인 책.
알림 팝업으로 띄우지 않는다.

## 7. 운영

트레이 축소·복귀, 크기 100/75/50%, 자동 시작(기본 OFF),
백업·복원, 버전 전환 백업, 단일 인스턴스, 자동 업데이트.

## 8. 디자인

- 폰트: 제목·말풍선 NanumSquareRound / 본문 Pretendard
  - **둘 다 SIL OFL 1.1 확인 완료.** 번들·재배포 허용, 단독 판매 금지,
    **라이선스 전문 동봉 필수.** `resources/fonts/README.txt`
  - 설치하지 않고 프로세스에만 등록한다(`theme.load_bundled_fonts()`).
- 팔레트: `src/readingsnail/theme.py` — **WCAG 대비를 계산해 맞췄다.**
  채우기용(`moss`)과 글자용(`moss_text`)·배경용(`moss_deep`)을 나눈다.
- 그림체: **선명한 외곽선의 스티커풍.** 부드러운 번짐·발광은 색상 키 투명도에서
  테두리 얼룩으로 나타나므로 쓰지 않는다.
- 소품은 별도 레이어. 캐릭터 프레임을 다시 그리지 않고 붙인다.
