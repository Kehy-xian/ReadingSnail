책 읽는 달팽이 — 테스트앱

■ 새 버전 받기

  https://github.com/Kehy-xian/ReadingSnail/releases/latest
  압축을 풀어 이 폴더를 통째로 바꾸면 됩니다. 기록은 다른 곳에 있어 남습니다.

■ 실행

  이 폴더의 ReadingSnail.exe 를 더블클릭하세요.
  설치 과정이 없습니다. 폴더를 통째로 원하는 곳에 두고 쓰시면 됩니다.

  처음 켤 때 Windows 가 "PC 보호" 파란 창을 띄울 수 있습니다.
  서명하지 않은 프로그램이라 그렇습니다. '추가 정보' → '실행'.

■ 쓰는 법

  달팽이를 마우스 오른쪽 단추로 누르면 메뉴가 나옵니다.
    기록 남기기 / 책 등록 / 내 서재 / 책장 / 이번 주 / 소품 / 설정

  달팽이를 더블클릭해도 기록 창이 열립니다.
  드래그해서 옮길 수 있고, 공중에서 놓으면 떨어집니다.

■ 기록이 저장되는 곳

  %LOCALAPPDATA%\ReadingSnail

  이 폴더는 앱 폴더와 따로 있습니다. 앱 폴더를 지워도 기록은 남습니다.
  기록을 완전히 지우시려면 저 폴더를 직접 지우세요.
  탐색기 주소창에 %LOCALAPPDATA%\ReadingSnail 을 붙여넣으면 열립니다.

■ 아직 안 되는 것 (알고 계셔야 합니다)

  · 그림이 자리표시입니다. 진짜 달팽이 그림(원화)이 아직 없습니다.
  · 책 검색이 안 됩니다. 국립중앙도서관 인증키를 설정 창에 넣어야 합니다.
    키가 없어도 '책 등록' 창에서 직접 입력하면 됩니다 — 언제나 되는 길입니다.
  · 달팽이가 비슷한 옛 기록을 꺼내는 기능(되살리기)이 쉽니다.
    번들 모델이 아직 안 들어갔습니다. 기록은 정상적으로 쌓입니다.
  · 자동 업데이트가 없습니다. 새 zip 을 받아 폴더를 바꾸시면 됩니다.

■ 이상한 점을 보시면

  같은 폴더에 error.log 가 생겼는지 봐 주세요.
  그 파일과 '무엇을 하다 그랬는지'를 알려주시면 고칠 수 있습니다.
